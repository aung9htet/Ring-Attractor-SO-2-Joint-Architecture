# Archived scripts

Tools that only served reports which are now in the repository's `docs/archive/`.
They still run (from the package root, e.g. `python3 -B scripts/archive/speed_report.py ...`),
but nothing current depends on them except one unit test of `sweep_feedback.analyse`.

| Script | Wrote |
| --- | --- |
| `bounded_ring_report.py` | the tables of `docs/archive/velocity/bounded-ring.md` |
| `speed_report.py` | the tables of `docs/archive/velocity/speed.md` and `all-joints.md` |
| `sweep_feedback.py` | the encoder-mode sweep of `docs/archive/blocks/feedback.md` |
